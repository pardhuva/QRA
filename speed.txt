| Concept          | Formula                                  | Meaning                      |
| ---------------- | ---------------------------------------- | ---------------------------- |
| Work             | ( {Time} *{Efficiency} )                 | Basic definition             |
| Efficiency       | ( 1/{Time} )                             | 1-day work                   |
| Time (A+B)       | ( xy / (x + y) )                         | When both work together      |
| Efficiency Ratio | ( 1/{Time Ratio} )                       | Inverse relation             |
| Wage Ratio       | = Efficiency Ratio                       | Based on work done           |
| Pipe fill/empty  | ( 1/x ± 1/y )                            | Net rate                     |
